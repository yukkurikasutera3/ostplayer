2. 【音響・MIDI・重要アーキテクチャ要件 (Key Architecture & Gotchas)】
--------------------------------------------------------------------------------
(1) SoundFont 即時切り替え (Hot-Swapping):
    - セッション中に SoundFont (.sf2 / .sf3) を変更・ロードした際、
      新規 WorkletSynthesizer の初期化完了 (spessaSynthInstance.isReady) を待機してから
      addSoundBank を呼び出すこと。
    - 古い Sequencer を確実に破棄し、new window.SpessaSynth.Sequencer(this.synth) を再バインドすること。
    - Web Audio 出力ルーティング (destNode / singleGainNodes[0] -> EQ/FX グラフ) を再接続し、
      アプリ再起動なしで選択した SoundFont で即座に MIDI が発音すること。

(2) MIDI ミキサー即時音色反映 (Real-time Instant Instrument Switching):
    - プリセット選択時および各チャンネルの楽器変更時に、再生中の旧音色ボイスを即座に停止 (stopAllNotes(true)) し、
      新音色 (Program Change) をリアルタイムに合成エンジンへ送信すること。
    - presetLock 機構により、MIDI シーケンス内部の Program Change による意図しない音色上書きを防止すること。
    - トラックごとの音量、ミュート、ソロ、カスタム音色設定は楽曲ごとに自動保存・自動復元すること。

(3) In-App アップデート確認 (GitHub Releases Update Checker):
    - GitHub Releases API (https://api.github.com/repos/yukkurikasutera3/ostplayer/releases/latest) と連携。
    - セマンティックバージョニング比較 (compareVersions) により最新版の有無を自動判定。
    - ダウンロードボタン押下時は、添付された Windows パッケージ ZIP (またはソースコード ZIP) の
      直通ダウンロード URL を開き、ブラウザ上で即座に自動ダウンロードを開始させること。
    - 起動時の自動確認は 3.5 秒遅延実行とし、UI 描画ラグを発生させないこと。

(4) 動画再生 (Video Sync):
    - 単一の <video> 要素を Web Audio API (createMediaElementSource) に直結し、
      0ms ハードウェア同期で音声と背景動画を再生すること。
    - クロスフェード完了時は旧動画ソースを確実にアンロード・クリーンアップすること。

(5) Discord Rich Presence (RPC):
    - Windows Named Pipe ネイティブ通信（外部 npm 依存ゼロ）を使用。
    - 楽曲情報（タイトル・アーティスト・再生時間・モード）をリアルタイム同期し、終了時に切断すること。

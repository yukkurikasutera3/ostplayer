OST Player Help

基本操作

音楽ファイルをウィンドウにドラッグ＆ドロップしてライブラリに追加します。再生したいモードを選んでから、リストの曲をクリックしてください。

MIDI再生 (Full Support)

すべてのモード（Single, Dual, Multi, FX, Visual）でMIDIファイル（.mid）を再生できます。高性能な内蔵シンセサイザーにより、ダウンロード待ち時間なしで即座に再生されます。DualやMultiで他の曲とミックスすることも可能です。

各モードの仕様

Single Mode

最もシンプルなプレイヤーです。オートクロスフェードやループ再生、MIDI再生に対応しています。

Dual Mode

2つのデッキ（A/B）を使ってDJのように曲をミックスできます。MIDIファイルもクロスフェードできます。

Multi Mode

デッキを好きなだけ追加して、複数の曲を同時に重ねて再生できます。

FX Mode

イコライザー、リバーブ、重低音強化などのエフェクトをかけて再生できます。MIDIファイルにもエフェクトが適用されます。

Visual Mode

音楽を視覚的に楽しむモードです。

ショートカットキー

Space : 再生 / 一時停止 (全モード)
1 〜 6 : モード切替 (Single, Dual, Multi, FX, Visual, Help)
← / → : 前 / 次の曲 (Single, Visual, FX)
↑ / ↓ : 音量の上下 (アクティブなプレイヤー)
[ / ] : クロスフェーダー調節 (Dualモード)
M : 全体消音 (ミュート) の切り替え

データ保存

追加した曲や設定、SoundFont はブラウザ内のデータベース (IndexedDB) に安全に保存されます。

v2.6.0 Exporter Update
🚀 最新アップデート (v2.6.0) 2026-08-12
  • 💾 MIDI → WAV Audio 変換書き出し: SGM などの SoundFont で演奏している MIDI トラックを、ワンクリックで高音質 WAV ファイルに変換・エクスポート保存する機能を追加。
  • ⏸️ SpessaSynth シームレス一時停止 (Pause / Resume): カスタム SoundFont 再生中も演奏位置を維持したまま一時停止・再開をスムーズに行えるよう改修。
  • ⚡ SoundFont 常時表示バッジ: 現在適用中の SoundFont (SGM / Built-in) をヘッダーに可視化。簡単選択＆即時リセット対応。
🎉 最新アップデート (v2.5) 2026-08-11
  • 音量制御の修正: FXモード切り替え時に音量が半減する不具合を修正し、全モード間でマスター音量をリアルタイム双方向同期。
  • FXモード再生ヘッダー同期: タブ切り替え時に曲を途切れさせず、曲名・再生/一時停止状態・経過時間をリアルタイム完全同期。
  • ライブラリ再生中同期: Single, Dual (Deck A/B), Multi (Deck N), FX モードで選択中の曲に動的バッジと点滅インジケーターを表示。並び替えドラッグ時も追尾。
  • 3D Spatial Audio & 8D Orbit 強化: 2D Panner パッドの直接ドラッグ移動に対応し、「↺ 初期位置に戻す (真中央)」ボタンを追加。
  • マスターフィルター機能: FX モードに Lowpass Cut (高音カット) / Highpass Cut (低音カット) フィルターを新設し Web Audio グラフへ統合。
✨ バッチ2 新機能リリース (v2.0) 2026-08-10
  • ID3 Tag & カバーアート表示: MP3 などの埋め込みアルバムアートワーク（APIC）と ID3 Metadata の自動読み込みに対応。
  • プレイリスト高度化: ドラッグ＆ドロップによる自由な並び替え（⋮⋮）、プレイリスト名の変更（✏️）、複製（📋）、JSON 入出力機能を追加。
  • ピッチロック (Pitch Lock): 再生速度を変更しても音階が変わらない preservesPitch トグルスイッチを搭載。
  • カスタム背景画像: ユーザー独自の背景画像のアップロード、ぼかし・暗さ・カード透明度の細かな調整機能を追加。
  • セッション録音 (Rec Session): プレイヤーの全出力をブラウザ上で高音質 WAV 録音・ダウンロード可能に。

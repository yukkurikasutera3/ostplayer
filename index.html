基本操作

音楽ファイルをウィンドウにドラッグ＆ドロップしてライブラリに追加します。再生したいモードを選んでから、リストの曲をクリックしてください。

MIDI再生 (Full Support)

すべてのモード（Single, Dual, Multi, FX, Visual）でMIDIファイル（.mid）を再生できます。高性能な内蔵シンセサイザーにより、ダウンロード待ち時間なしで即座に再生されます。DualやMultiで他の曲とミックスすることも可能です。

各モードの仕様

Single Mode

最もシンプルなプレイヤーです。オートクロスフェードやループ再生、MIDI再生に対応しています。

Dual Mode

2つのデッキ（A/B）を使ってDJのように曲をミックスできます。MIDIファイルもクロスフェードできます。

Multi Mode

デッキを好きなだけ追加して、複数の曲を同時に重ねて再生できます。

FX Mode

イコライザー、リバーブ、重低音強化などのエフェクトをかけて再生できます。MIDIファイルにもエフェクトが適用されます。

Visual Mode

音楽を視覚的に楽しむモードです。

ショートカットキー

Space : 再生 / 一時停止 (全モード)
F11 : フルスクリーンの切り替え
1 〜 6 : モード切替 (Single, Dual, Multi, FX, Visual, Help)
← / → : 前 / 次の曲 (Single, Visual, FX)
↑ / ↓ : 音量の上下 (アクティブなプレイヤー)
[ / ] : クロスフェーダー調節 (Dualモード)
M : 全体消音 (ミュート) の切り替え

データ保存

追加した曲や設定、SoundFont はブラウザ内のデータベース (IndexedDB) に安全に保存されます。

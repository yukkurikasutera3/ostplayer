[v3.2.0] - 2026-09-12
--------------------------------------------------------------------------------
【MIDIミキサー個別保存・プリセット管理 / 即時音色反映 / SoundFont即時切り替え修復 / 実績システム拡張 (全40種)】
・SoundFont即時切り替え (Hot-Swapping) の完全修復:
  - セッション中にSoundFont (.sf2 / .sf3) を変更・ロードした際、新規WorkletSynthesizerの初期化完了 (isReady) を待機してからSoundBankを追加し、SequencerおよびWeb Audioルーティング（destNode / gainNode）を自動再構築・再バインド。アプリを再起動することなく、選択したSoundFontで即座にMIDIが発音・再生されるよう修正。
  - SoundFontリセット時も古いシンセインスタンスを確実に破棄し、デフォルト音源（WebAudioTinySynth）へシームレスにフォールバック。
・MIDIミキサーの即時音色反映 (Real-time Instant Instrument Switching):
  - プリセット選択時および各チャンネルの楽器変更時に、再生中の旧音色ボイスを即時停止し、新音色（Program Change）をリアルタイムに合成エンジン（SpessaSynth / WebAudioTinySynth）へ即時反映。
  - MIDIシーケンス再生中の音色イベントによる上書きを防止するプリセットロック機構を搭載。
・MIDIミキサー設定の永続化とトラック別自動復元:
  - 各MIDI楽曲ごとに設定した16チャンネルの音量 (Volume)、ミュート (Mute)、ソロ (Solo)、カスタム楽器音色 (Program Change) を localStorage および IndexedDB に自動保存・永続化。
  - 楽曲切り替え時に保存済み設定を自動検出し、ミキサーUI（スライダー・ボタン・ドロップダウン）およびSpessaSynth合成エンジンへ自動適用。
  - 「設定を保存」ボタンおよび「保存設定」ステータスバッジの追加。
  - 「リセット」ボタンで初期状態（全チャンネル音量100・ミュート/ソロ解除・元の音色）へワンクリック初期化可能。
・MIDIミキサー・ワンクリックプリセット機能:
  - プリセットドロップダウンメニューを新設:
    * Piano Focus (ピアノ強調: メロディピアノ強調、他パート減衰)
    * Acoustic Ensemble (アコースティック合奏: ギター・ベース・バイオリン・フルート等)
    * 80s Synthwave (80s シンセウェーブ: リード・シンセベース・ウォームパッド・シンセストリングス等)
    * Orchestral (オーケストラ: ストリングス・フレンチホルン・チェロ・ハープ・ブラス等)
    * 8-Bit Chiptune (8-Bit チップチューン: パルス波・矩形波・ノコギリ波リード等)
    * 全チャンネル解除 (Unmute All)
    * デフォルト (標準バランス)
・In-App アップデート確認 & GitHub Releases 連携 (Update Checker):
  - GitHub Releases API (https://api.github.com/repos/{owner}/{repo}/releases/latest) から最新バージョンとリリースノートを取得し、アプリ内で更新通知・ダウンロード画面を表示するアップデートチェッカーを新設。
  - セマンティックバージョニング比較 (compareVersions) により、最新バージョンが公開されているかを自動判定。
  - ヘルプ画面に「ソフトウェア更新 (Software Updates)」設定カードを追加:
    * 現在バージョンバッジ (v3.2.0) および更新ステータスバッジの表示。
    * GitHub リポジトリ指定フィールド (デフォルト: yukkurikasutera3/ostplayer、localStorage 永続保持、初期値リセットボタン付き)。
    * 起動時の自動更新確認トグルスイッチ (localStorage 永続保持)。
    * 「Releases ページを開く」「更新を確認」ボタン（ローディングスピナー＆インライン通知対応）。
  - アップデート通知モーダル (Update Modal) を新設:
    * 現在バージョンと最新バージョンの比較表示 (v3.2.0 -> v3.x.x)、公開日、リリースタイトル、ダウンロード対象ファイル名・容量を表示。
    * フォーマット済みリリースノート・Changelog 閲覧ボックス (スクロール対応)。
    * 「最新版を自動ダウンロード (ZIP)」ボタン: GitHub Release に添付された Windows パッケージ ZIP (またはソースコード ZIP アーカイブ) の直通ダウンロード URL を開き、ブラウザ上で即座に自動ダウンロードを開始。
    * 「Releases ページ」ボタン: GitHub Releases の Web ページを直接閲覧可能。

[v3.1.0] - 2026-09-11
--------------------------------------------------------------------------------
【最新アップデート & 重要不具合修正 (全6項目)】
・SoundFont 選択ダイアログの二重表示修正:
  - SoundFont変更ボタンクリック時にファイル選択ダイアログが2回開くイベント重複発火を解消。
・SpessaSynth MIDI & Custom SoundFont 音声パイプラインの完全修復:
  - AudioWorklet 内の MIDI 非同期ロードと再生開始 (play) の競合を解消（ロード待機 Promise と pendingPlay 自動再生キューを実装）。
  - MIDI 再生時の Single デッキゲイン (singleGainNodes[0]) の音量初期化と Web Audio ルーティング再接続の切断・直結処理を最適化。
  - Sequencer の songChange / noteOn イベントハンドラーを再構築し、MIDI ミキサーの LED 点灯や曲終了時 (handleMidiEnded) の自動ループ・次曲遷移を安定化。
  - Multi-deck / Dual モードにおける SpessaSynth と WebAudioTinySynth の両対応・シームレス再生を実装。
・動画クロスフェード完了後の背景クリーンアップ:
  - 動画から別トラックへクロスフェードした際、完了後も前の動画フレームが背景に残ってしまう問題を修正。
  - クロスフェード完了時に動画要素を確実にアンロードし、背景動画表示状態 (updateVideoBackgroundState) を正確に同期。
・Dual モードから Single モードへのトラック漏洩防止:
  - Dual デッキ A で再生した曲が、Single モード側で未選択時に意図せず再生される問題を解消。
  - モード切替時および Single 再生時に Single モード側のプレイリストとプレイヤー URL を確実に検証・同期するようデッキ間を完全隔離。
・大画面ビジュアルモード「🔮 Quantum Orb」新搭載:
  - 変化の少なかった Cyber Grid を、大迫力の「🔮 Quantum Orb」へフルリニューアル。
  - 音声の低音・周波数にダイナミック連動する多層プラズマコア、3重の3Dオービット粒子リング、ソーラーフレア波形、ベース衝撃波リング、星雲ダストパーティクルを実装。
・プレイリスト JSON エクスポート / インポートの完全復元:
  - JSON エクスポート時に楽曲のローカル絶対パス (filePath) およびメタデータを保存するよう拡張。
  - JSON インポート時に Electron ネイティブ IPC 経由で実ファイルデータを自動読み込みし、IndexedDB 登録とプレイリストへの自動追加・完全復元に対応。
